Bu klasör, sistemin **v1 kararlı sürümünü** içeren bağımsız arşiv ve çalışma alanıdır.

---

## 📁 Klasör İçeriği

* **`index.html`**: v1 Standart / Akademik BTY BEP Modülü
* **`index2.html`**: v2 Temel / Uygulamalı BTY BEP Modülü
* **`index3.html`**: v3 Maarif Modeli & UDA Destekli BTY BEP Modülü
* **`Code.gs`**: Sayfalar arası `?page=index`, `?page=index2`, `?page=index3` yönlendirmesini yapan Google Apps Script sunucu betiği
* **`docx.umd.js`**: Çevrimdışı Word aktarımı için yerel kütüphane

Tüm sayfalar birbirine bağlantılıdır; URL parametreleri ve üst navigasyon menüsü üzerinden sayfalar arası geçiş sorunsuz çalışır.
